# Git

¿Qué es un repositorio?
Es una carpeta que guarda las versiones de su contenido, dejando un registro de los cambios. Permite volver a una versión anterior sin problema.

¿Qué diferencia hay entre Git y GitHub?
Git es una herramienta de control de versiones: permite controlar y almacenar las versiones de un mismo proyecto o carpeta, y funciona en mi ordenador sin internet. GitHub es un servicio online que permite alojar repositorios.

¿Qué hace `git status`?
Me dice qué cambios he hecho desde el último commit y si ya están preparados con `git add` (verde) o no (rojo).

¿Qué hace `git add`?
Prepara los cambios para el próximo commit (es meterlos en la caja). Con `git add .` preparo todos los cambios.

¿Qué hace `git commit`? ¿Por qué lleva un mensaje?
Guarda una versión de los archivos en el repositorio, en mi ordenador. El mensaje es una etiqueta para saber qué cambió en esa versión.

¿Qué hace `git push`?
Sube a GitHub los commits que GitHub todavía no tiene.
